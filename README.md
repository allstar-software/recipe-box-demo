# Recipe Box

A small React app for browsing recipes: search them, filter by how long they take, and open one to see its ingredients and method. Add recipes to "My week" to get one summed shopping list; the week is saved in the browser.

    npm install
    npm run dev      # http://localhost:5173
    npm test         # unit tests for the week and shopping list logic

Or with Docker: `docker compose up`.
